Welcome to **CS101**, a production-grade software engineering curriculum and personal learning operating system.

## ⚡ The 15-Folder Learning Operating System

Each domain contains the following structure:
1. `notes/` — First-principles theory templates
2. `mental-models/` — Blank ASCII diagrams to complete
3. `drills/` — Muscle-memory exercises
4. `problems/` — Coding challenges with Jest unit tests
5. `assignments/` — Real Jira-style tickets
6. `projects/` — Architecture specs (Mini, Intermediate, Production)
7. `experiments/` — Intentionally breaking things to observe browser/engine behavior
8. `interview/` — Theory, Coding, Debugging, Production & Behavioral questions
9. `real-world/` — Production usage at Stripe, Razorpay, CRED, Vercel
10. `teach-back/` — Feynman Technique prompts
11. `references/` — Engineering handbook
12. `revision/` — Spaced repetition quizzes (Day 1 to Day 120)
13. `mistakes/` — Mistakes log
14. `progress/` — Machine-readable state tracking (`progress.yaml`)
15. `journal/` — Daily learning diary
