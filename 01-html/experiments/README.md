# Experiments: Intentionally Breaking HTML & Observing Browser Engine Behavior

Run these experiments by creating test HTML files and observing the behavior in Google Chrome DevTools / V8 / Blink parser.

---

## Experiment 1: The Missing DOCTYPE (Quirks Mode vs Standards Mode)
- **Action**: Create two HTML files—`standards.html` with `<!DOCTYPE html>` and `quirks.html` with NO DOCTYPE. Put an `<img>` tag next to an inline `<span>` in both.
- **Run in Browser**: Inspect `document.compatMode` in DevTools Console for both files.
- **Questions to Answer**:
  1. What is `document.compatMode` in `quirks.html` vs `standards.html`?
  2. How does the browser layout engine handle font sizing, table cell inheriting, and inline element vertical alignment differently in Quirks mode?
  3. Why do legacy enterprise applications break when adding `<!DOCTYPE html>` retrospectively?

---

## Experiment 2: Nested `<form>` Tags & DOM Tree Repair
- **Action**: Create an HTML file containing a nested form: `<form id="outer"><form id="inner"><input type="text"></form></form>`.
- **Run in Browser**: Open DevTools Elements Inspector and inspect the DOM tree generated by the browser parser.
- **Questions to Answer**:
  1. Did the browser keep `<form id="inner">` inside `<form id="outer">` in the DOM tree?
  2. Why does the HTML parser spec forbid nested `<form>` elements?
  3. What happens to form submission payloads when a user clicks a submit button inside a nested form?

---

## Experiment 3: Script Tag Parsing Block (`async` vs `defer` vs Blocking)
- **Action**: Create an HTML document with 5,000 DOM elements. Insert a script tag `<script src="large-script.js"></script>` in `<head>` that delays for 3 seconds on the server.
- **Observe**: Record Performance trace in Chrome DevTools.
- **Compare**:
  - Test A: Plain `<script>` in `<head>`
  - Test B: `<script async>` in `<head>`
  - Test C: `<script defer>` in `<head>`
  - Test D: Plain `<script>` at bottom of `<body>`
- **Questions to Answer**:
  1. How many milliseconds was the First Contentful Paint (FCP) delayed in Test A vs Test C?
  2. In what order do scripts execute when 3 `async` scripts finish fetching in random sequence?

---

## Experiment 4: Invalid Tag Interleaving (`<b><i>text</b></i>`)
- **Action**: Write `<p>Hello <b>bold <i>and italic</b> only italic</i> normal</p>`.
- **Run in Browser**: Inspect `document.querySelector('p').innerHTML` and DOM tree.
- **Questions to Answer**:
  1. How did the HTML parsing algorithm (Adoption Agency Algorithm) fix the misplaced closing `</b>` tag?
  2. How many DOM nodes were created in memory to fix this overlap?

---

## Experiment 5: Unescaped User Content & XSS Injection
- **Action**: Inject string `<img src="x" onerror="alert('XSS')">` into an element using `innerHTML` vs `textContent`.
- **Questions to Answer**:
  1. Why does `element.innerHTML = userInput` execute the malicious script while `element.textContent = userInput` escapes it?
  2. How does the browser HTML parser treat entity-encoded characters like `&lt;script&gt;`?
