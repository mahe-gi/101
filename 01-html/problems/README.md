# Problems: HTML Engineering Challenges

Each problem includes a README spec, an `index.html` file (where you write your code), and a `index.test.js` file (which validates your markup using JSDOM + `@testing-library/dom`).

Run tests using:
```bash
cd 01-html
npm test
```
