# 01-HTML: Deep Engineering & Fundamentals Roadmap

Welcome to Domain 01: **HTML**.

HTML (HyperText Markup Language) is not merely tags on a page—it is the foundational data structure of the Web. It defines document semantics, accessibility (A11y) tree generation, browser parsing models, SEO indexing, and user agent behavior.

---

## 🗺️ Topic Checklist

- [ ] **01-Document Structure & DOCTYPE** (Quirks mode, Document Parsing, DOM Nodes)
- [ ] **02-Semantic Elements** (`<article>`, `<section>`, `<nav>`, `<aside>`, `<header>`, `<footer>`, `<main>`)
- [ ] **03-Forms & Input Constraints** (Validation API, Input types, Accessibility labels, EncTypes)
- [ ] **04-Accessibility & ARIA** (A11y tree, Roles, States, Properties, Landmark regions, Keyboard nav)
- [ ] **05-Media & Responsive Images** (`<img>`, `<picture>`, `srcset`, `sizes`, `loading="lazy"`, `fetchpriority`)
- [ ] **06-Head, Meta & SEO** (Viewport, OpenGraph, Canonical URLs, Content Security Policy, Charset)
- [ ] **07-Hyperlinks & Resource Hints** (`rel="noopener noreferrer"`, `preload`, `prefetch`, `dns-prefetch`, `preconnect`)
- [ ] **08-Security & Sandboxing** (`<iframe>`, `sandbox` attribute, `srcdoc`, XSS mitigation in DOM)
